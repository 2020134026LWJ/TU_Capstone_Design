# Config

시스템 설정 파일들

## 파일 목록

| 파일 | 설명 |
|------|------|
| `map.json` | 창고 맵 (노드, 간선) |
| `robot_config.json` | 로봇 설정 |
| `shelf_config.json` | 선반/물품/작업대 설정 |

## map.json

8×4 그리드 맵 (34개 노드: 32 그리드 + 2 작업대)

```json
{
  "grid_size": {"cols": 8, "rows": 4},
  "shelf_nodes": [11, 12, 14, 15, 19, 20, 22, 23],
  "workstation_nodes": [33, 34],
  "nodes": [
    {"id": 1, "row": 0, "col": 0, "type": "M"},
    {"id": 11, "row": 1, "col": 2, "type": "S"},
    {"id": 33, "type": "W"}
  ],
  "edges": [
    {"from": 1, "to": 2, "cost": 1.0}
  ]
}
```

### 노드 타입
- `M` (Passage): 통로
- `S` (Shelf): 선반 위치
- `W` (Workstation): 작업대

## 맵 시각화 (8×4 그리드)

```
W1(33)── 1 ─ 2 ─ 3 ─ 4 ─ 5 ─ 6 ─ 7 ─ 8    (row 0, 통로)
         |   |   |   |   |   |   |   |
         9 ─10 ─[11]─[12]─13 ─[14]─[15]─16   (row 1, []=선반)
         |   |   |   |   |   |   |   |
        17 ─18 ─[19]─[20]─21 ─[22]─[23]─24   (row 2, []=선반)
         |   |   |   |   |   |   |   |
W2(34)──25 ─26 ─27 ─28 ─29 ─30 ─31 ─32    (row 3, 통로)

[N] = 선반 노드
W1(33): gateway=1, staging=9, trigger=2
W2(34): gateway=25, staging=17, trigger=26
```

- **M (통로)**: 26개 — 로봇 이동 경로 (선반/작업대 제외 노드)
- **S (선반)**: 8개 — 11, 12, 14, 15, 19, 20, 22, 23
- **W (작업대)**: 2개 — 33(W1), 34(W2)
- **총 노드**: 34개 (32 그리드 + 2 작업대)
