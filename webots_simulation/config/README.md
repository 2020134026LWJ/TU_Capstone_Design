# Config

시스템 설정 파일들

## 파일 목록

| 파일 | 설명 |
|------|------|
| `map.json` | 창고 맵 (노드, 간선) |
| `robot_config.json` | 로봇 설정 |
| `shelf_config.json` | 선반/물품/작업대 설정 |

## map.json

7x7 그리드 맵 (51개 노드)

```json
{
  "nodes": [
    {"id": 1, "x": 0.0, "y": 0.0, "type": "M"},
    {"id": 9, "x": 1.0, "y": 1.0, "type": "S"},
    {"id": 50, "x": -1.0, "y": 0.0, "type": "W"}
  ],
  "edges": [
    {"from": 1, "to": 2, "cost": 1.0}
  ]
}
```

### 노드 타입
- `M` (Passage): 통로
- `S` (Shelf): 선반 위치
- `W` (Workstation): 작업대

## robot_config.json

```json
{
  "robots": {
    "1": {"home_node": 50, "name": "AGV-1"},
    "2": {"home_node": 51, "name": "AGV-2"}
  }
}
```

## shelf_config.json

```json
{
  "shelves": {
    "9": {"label": "S1", "items": ["A", "B", "C"]},
    "11": {"label": "S2", "items": ["D", "E", "F"]}
  },
  "workstations": {
    "50": {"label": "W1", "gateway_node": 1},
    "51": {"label": "W2", "gateway_node": 43}

```
